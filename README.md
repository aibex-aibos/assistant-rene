# assistant-rene

Assistent *Rene* von AIbex AIOS, Version 0.1.0: Spezialist für Recherche. Sein erster Skill `rene-begriff` erfasst, was in der veröffentlichten Welt unter einem neuen Begriff verstanden wird. Jede Antwort beginnt mit „🕵🏻‍♂️ ".

## Holen

**Voraussetzung:** AIbex AIOS v0.5 oder v0.6 ist installiert, und der Vault oder das Projekt ist aktiviert.

```bash
aios --fetch assistant-rene
```

Zuordnen mit `/aios-assistant Rene` im Projekt, in dem recherchiert wird. Rene und sein Skill wirken **ab dem nächsten Chat** in diesem Projekt.
